## Component Breakdown

### 1. Navigation Bar
**Elements:**
- Logo (left-aligned)
- Navigation links: Home, Features, Pricing, Docs
- Auth buttons: Login (outlined), Sign Up (filled)

**Tech Noir Theme:**
- Dark background with yellow accent on hover
- Sharp edges, neon glow on active items

### 2. Hero Section
**Elements:**
- Animated particles background
- Main headline with glitch effect
- Subheadline
- Two CTAs: Primary (filled) + Secondary (outlined)
- Trust badges row

**Tech Noir Theme:**
- Black background
- Yellow (#FFD700) primary accent
- Purple (#A855F7) secondary accent
- Animated cursor follower effect

### 3. How It Works
**Elements:**
- Section header with "View All Steps" link
- 4-step horizontal cards
- Icon + number + title + description

**Tech Noir Theme:**
- Cards with 2px borders
- Shadow effects on hover
- Neon glow on icons

### 4. Features Section
**Elements:**
- 3-column feature cards
- Icon, title, description, details list

**Tech Noir Theme:**
- Glass-morphism cards
- Gradient borders
- Hover lift effect

### 5. Live Demo Section
**Elements:**
- Interactive prompt input
- Tier selector (radio buttons)
- Generate button
- Result preview box

**Tech Noir Theme:**
- Terminal-like result box
- Neon input focus states
- Glowing button effect

### 6. Testimonials
**Elements:**
- Star ratings
- Quote text
- Author info (name, role)
- Horizontal scroll/carousel

**Tech Noir Theme:**
- Yellow stars
- Card with border shadow

### 7. CTA Section
**Elements:**
- Heading
- Subtext
- Two buttons
- Trust indicators

### 8. Footer
**Elements:**
- Logo + tagline
- 4-column link groups
- Social icons
- Copyright

| Action | Trigger | Result |
|--------|---------|--------|
| Navigate | Click nav links | Smooth scroll to section |
| Try Demo | Type in demo input | Live preview |
| Generate | Click generate in demo | Show sample result |
| Sign Up | Click "Get Started" | Navigate to signup |
| Login | Click "Login" | Navigate to login |
| View Pricing | Click pricing link | Navigate to pricing page |

---

## Mobile Responsive Notes

### Breakpoints:
- **Desktop (>1024px):** Full layout as shown
- **Tablet (768-1024px):** 2-column features, stacked testimonials
- **Mobile (<768px):**
  - Hamburger menu
  - Single column layout
  - Stacked cards
  - Demo section full-width
  - Touch-friendly buttons (min 44px)

### Mobile Adjustments:
- Hero text: 40px → 28px
- Cards: Horizontal → Vertical stack
- Demo: Inline tier selector
- Testimonials: Vertical scroll

## Tech Noir Theme References

### Colors:
- **Primary Background:** #0A0A0A (Black)
- **Secondary Background:** #1A1A1A (Dark Gray)
- **Primary Accent:** #FFD700 (Yellow/Gold)
- **Secondary Accent:** #A855F7 (Purple)
- **Text Primary:** #FFFFFF (White)
- **Text Secondary:** #A1A1AA (Gray)

### Typography:
- **Headlines:** JetBrains Mono / Orbitron (bold, uppercase)
- **Body:** Inter (clean, readable)
- **Code:** JetBrains Mono

### Effects:
- Neon glow on hover
- 2px solid borders
- Shadow offset (4px, 4px)
- Glitch text animation
- Particle background
